# Синтетический датасет: выгорание учителей (v2)

```
pip install numpy pandas pyyaml scikit-learn
python generate.py                                            # config/default.yaml -> data/teacher_burnout.db
python generate.py --config config/scenarios/easy.yaml --out data/easy.db
python generate.py --set groups.burnout_share=0.4 --set absence.enabled=false
python baseline.py data/teacher_burnout.db                    # проверка предсказуемости таргета
```

На выходе:
- `*.db` — SQLite с таблицами и вью;
- `*_panel.csv` — выгрузка `teacher_burnout_panel`;
- `*_config.yaml` — итоговый конфиг прогона.

## Файлы
| Файл | Что внутри |
|---|---|
| `config/default.yaml` | все параметры с комментариями; почти у каждого блока есть `enabled` |
| `config/scenarios/easy.yaml` | реалистичные эффекты выключены (сигнал сильный, для отладки) |
| `config/scenarios/high_burnout.yaml` | 40% выгоревших, чаще опросы |
| `config/scenarios/small_test.yaml` | 40 учителей, 4 месяца — быстрый прогон |
| `sql/schema.sql`, `sql/views.sql` | DDL и вью |
| `generate.py` | генератор |
| `baseline.py` | бейзлайн-модель с GroupKFold по учителям |

## Таблицы
Все таблицы из ТЗ. Сверх ТЗ добавлено:
- **`user_absence`** — больничные. В реальности они придут из HR-системы.
- **`teacher_burnout_panel_ext`** — панель из ТЗ плюс колонка `sick_days`.
- **`burnout_type_dic`** — справочник «тип → уровень».
- **`_gen_teacher_truth`, `_gen_teacher_week_truth`** — скрытые параметры генератора. Только для анализа, **не использовать как признаки**.

## Что моделируется
| Эффект | Блок конфига | Суть |
|---|---|---|
| Профили | `groups` | Перегрузка / отстранение / устойчивые с высокой нагрузкой / здоровые. Типы смешиваются (`type_mixing`). Выраженность в поведении у каждого учителя своя (`behavior_expression`): часть выгоревших внешне почти не меняется. |
| Динамика | `burnout_dynamics` | S-кривая с пиком через 4–20 недель, неровная траектория. 35% выгоревших уже выгорели к сентябрю. Возможно частичное восстановление после каникул. У «перегруженных» нагрузка растёт на 2–8 недель раньше выгорания. |
| Сезонность | `seasonality` | Начало года, концы четвертей (всплеск выставления оценок), ВПР, экзамены. Влияют на всех: растут нагрузка и активность, а через стресс — и ответы в опросах. |
| Шоки школ | `seasonality.school_shocks` | Проверки и т.п.: 1–3 недели повышенной нагрузки у всех учителей школы. |
| Расписание | `timetable` | Фиксированный шаблон на полугодие по ставке (18 ч), учителя начальных классов и предметники, отмены уроков, замены (при перегрузке их больше). Продлёнка только в начальной школе, консультации к ОГЭ/ЕГЭ — только у тех, кто ведёт 9-е/11-е классы. |
| Активность | `activity` | Оценки и ДЗ появляются после уроков с задержкой. Фоновая активность идёт сессиями, бывают всплески по дням. У перегруженных больше вечерней работы. |
| Опросы | `survey` | Волны раз в 4 недели с окном 2 недели. Выгоревшие отвечают реже (MNAR), с каждой волной откликается меньше людей. Бывают повторные прохождения. |
| Больничные | `absence` | Чаще при выгорании и в сезон гриппа. Во время больничного нет событий и почти нет активности. |
| Найм и увольнения | `churn` | 5% учителей нанимают в течение года. Вероятность увольнения растёт с выгоранием, поэтому часть выгоревших выпадает из данных до опроса. |
| Грязь | `data_quality` | Дни сбоя выгрузки у всех, пропущенные недели у отдельных учителей, дубли в логе (~0.5%), события, не попавшие в календарь. |

## Предсказуемость (`baseline.py`, таргет — уровень ≥ 2)
| Сценарий | Сырые признаки | + скользящие / относительно личной нормы |
|---|---|---|
| `easy` | 0.71 | 0.99 |
| `default` | 0.58 | 0.69 (на сидах 7 и 123: 0.65 и 0.77) |
| `high_burnout` | 0.62 | 0.79 |

Если обучать по истинному скрытому уровню на всех неделях, получается ~0.78. Это потолок сигнала в признаках, разница с наблюдаемыми метками приходится на шум опроса и нехватку меток.

Разброс между сидами большой: выгоревших около 75 человек, позитивных меток 100–150. Сравнивать подходы лучше на нескольких сидах (`--set seed=N`) или на большем числе учителей (`--set scale.n_teachers=1000`).

## Как считается панель
- **`week_dt`** — понедельник недели. Сетка недель для каждого учителя идёт от первой до последней недели с данными, т.е. период работы.
- **`event_hours`** — сумма длительностей событий календаря.
- **`activity_hours`** — число разных часовых интервалов, в которых была хотя бы одна активность.
- **`act_avg_participants_per_hour`** — Σ(участники × часы) / Σ часов.
- **`burnout_level`** — MAX за неделю. На неделях без опроса — NULL.

## Рекомендации к обучению
- **Валидация** — только GroupKFold по `user_id`. Для честной оценки лучше дополнительно делать сдвиг во времени.
- **Признаки** — лучше всего работают относительные к личной норме и скользящие средние. Сезонность общая для всех, поэтому полезно нормировать признаки на среднее по школе за ту же неделю.
- **Пропуски таргета** неслучайны: выгоревшие реже отвечают. Сам факт неответа несёт информацию.
- **Регулировка сложности**: `groups.behavior_expression`, `survey.noise_sd`, `survey.wave_every_weeks`, `load.*_mult`, `activity.*_mult`.
