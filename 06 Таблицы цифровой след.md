Необходимо:
- создать БД с таблицами ниже
- наполнить таблицы данными по нескольким сотням учителей и по каждому несколько месяцев логов
- сделать таблицу teacher_burnout_panel как вью с понедельными агрегатами других таблиц
- отдельно создать конфиги с настройками генерации - чтобы можно было менять настройки распределения значений, например процент выгоревших сотрудников и кая часть из них сильнее загружена мероприятиями

Таблица с активностью user_activity_log:
- activity_id - id активности
- user_id - id пользователя
- activity_type -  тип активности
- act_msg_cnt - количество сообщений
- act_msg_char_cnt - количество символов в сообщениях
- activity_desc - описание активности
- activity_dttm - дата и время активности

Таблица с фактическим календарем user_act_schedule:
- schedule_id - id события
- user_id - id пользователя
- school_id - id школы
- event_id - id мероприятия
- dttm_from - дата и время начала
- dttm_to - дата и время конца
- class_id - id класса
- act_participants_cnt - фактическое количество участников

Таблица с результатами опросов survey_act:
- survey_id - id опроса
- user_id - id пользователя
- calendar_dt - дата опроса
- burnout_type - тип выгорания по результатам опроса

Справочник школ school_dic:
- school_id - id школы
- school_nm - наименование школы
- school_adr - адрес школы

Справочник школ user_dic:
- user_id - id пользователя
- user_nm - ФИО пользователя

Справочник классов class_dic:
- class_id - id класса
- class_nm - Наименование класса (4А, 5Б
- school_id - id школы

Справочник мероприятий event_dic:
- event_id - id мероприятия
- event_nm - наименование мероприятия (урок, продленка, родительское собрание)

Панель с фичами teacher_burnout_panel:
- user_id - id пользователя
- week_dt - дата начала недели
- event_hours - количество часов мероприятий
- activity_hours - количество часов активности в инструментах учителя
- act_avg_participants_per_hour - среднее количество участников в час
- act_msg_cnt - количество сообщений
- act_msg_char_cnt - количество символов в сообщениях
- burnout_level - уровень выгорания по результатам опроса (максимальный на неделе) - это таргет модели
